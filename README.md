# Clipy

Clipy는 웹 탐색 중 찾은 항목을 세션 단위로 관리하고, 비교와 최종 결정을 돕는 앱입니다.

사용자가 보던 맥락, 후보, 비교 상태를 잃지 않고 **결정까지 이어지는 흐름**에 집중합니다.

```
웹 탐색 → 아이템 수집 → 비교 맥락 유지 → 판단 기록 → 최종 결정
```

- 탐색 중 찾은 항목을 세션 단위로 기록합니다.
- 비교와 판단을 위한 상태를 앱에서 관리합니다.
- 재진입했을 때 이전 흐름을 자연스럽게 이어갑니다.

## Getting Started

개발 환경은 Android Studio와 프로젝트의 Gradle wrapper를 기준으로 합니다.

**Git hook 설치** (최초 1회)

```sh
sh scripts/install-git-hooks.sh
```
